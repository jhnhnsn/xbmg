# Changelog

What changed in xbmg for people who use it. The newest entries come first.

## Unreleased

- Install xbmg with one command, no sudo, if you have Node 20 or newer:
  `curl -fsSL https://raw.githubusercontent.com/jhnhnsn/xbmg/main/install.sh | sh`.
  Run it again to upgrade. ([#3](https://github.com/jhnhnsn/xbmg/issues/3))
- Install xbmg with Homebrew: `brew install jhnhnsn/tap/xbmg`. Homebrew
  installs Node for you. ([#2](https://github.com/jhnhnsn/xbmg/issues/2))
